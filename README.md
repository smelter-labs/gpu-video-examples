# gpu-video examples

Examples for [gpu-video](https://github.com/software-mansion/smelter/tree/master/gpu-video) that are too large for the main repository. Each is a separate crate:

```
cd egui-player
cargo run
```

## mp4 players

- `egui-player`: mp4 player built with egui
- `slint-player`: mp4 player built with slint
